# Reference sources

Only the public-domain Gray728 files and this note are tracked; the rest are
kept local (`.gitignore`), since this repository is public and their licences
are the owner's or unknown.

- `gray728-lateral.svg`, `gray728-lateral.png` — Wikimedia Commons
  [File:Gray728.svg](https://commons.wikimedia.org/wiki/File:Gray728.svg),
  "Lateral surface of left cerebral hemisphere, viewed from the side", after
  Henry Vandyke Carter's figure 728 in *Gray's Anatomy* (1918), vectorized by
  Mysid. **Public domain.** SVG fetched from
  `https://upload.wikimedia.org/wikipedia/commons/1/1a/Gray728.svg`; the PNG is
  Commons' own 960 px render of it. Used to proportion the brain's lateral
  silhouette (frontal lobe, the temporal lobe below the Sylvian fissure, the
  cerebellum tucked under the back, the brainstem) and to place the sulci.
- `PRIMARY-i2-side-view.png` — the primary target: an icon option from our
  subreddit work that Mike kept (side view, front left; region colours).
- `style-b2-banner.png` — a style cue only (circuit traces into dendrites, cyan to violet).
- `mike-hologram-reference.png` — the look Mike asked for (owner-provided; source unknown).
- `site-hologram-brain.png` — counterparts.ai's three.js point-cloud brain (ours).
- `video-brain.jpg` — a frame from our video (ours).
- `current-in-iterm-toggles-and-glow.png` — the sidebar before this work, in
  iTerm2 (owner's screenshot). Measured from it: a cell is about 8.1 x 16 px,
  braille dots cluster 2 x 4 per cell with wider gaps between cells.
