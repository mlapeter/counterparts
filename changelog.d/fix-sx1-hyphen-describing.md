- **A hyphenated password said in a sentence is redacted.** "my password is hunter-secret",
  "wifi pw sunset-river" and "the PIN is 44-71" were kept. A hyphenated value standing alone after a
  password's name is now taken, unless it plainly describes the password: "case-sensitive",
  "high-entropy", "8-chars", "well-known" and "top-secret" still read as sentences.
