- **The sidebar's fox no longer looks at your terminal's settings.** It used to read seven
  environment variables (`TERM_PROGRAM`, `TERM`, `TMUX` and others) to guess how to draw
  the fox. Now it tries a picture first, and where the terminal can't show one (Claude Code
  says so within a moment) it draws the half-block fox, which every terminal draws. The
  finer sextant fox is now a choice: `/counterparts avatar detail fine`. If you had it
  before in iTerm2, WezTerm or VS Code, run that once to get it back.
