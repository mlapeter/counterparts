- **A starter memory no longer pushes a lived match out of the deliberate `recall`.** On a new store, a seed that
  shared a word with the question set facts mode's "weak match" bar, and a lived memory found by meaning alone fell
  under it ("which coffee maker do we own?" lost the note about the espresso machine). A lived match's bar now comes
  from lived matches only. The single-binary check now runs on every pull request that touches `src/`.
