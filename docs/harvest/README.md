# The harvest — design inputs distilled from v1 (bansai)

Produced 2026-08-25 by six parallel harvest passes over the bansai repo, its decision
journal, its test suite, and its live telemetry. `SYNTHESIS.md` is the entry point —
note its three strata: owner-decided, settled evidence, and **proposals that are NOT
decisions**.

| file | what it is |
|---|---|
| `SYNTHESIS.md` | The stratified design brief; start here. |
| `behavioral-spec.md` | The WHAT of every lifecycle stage, mechanism-free, + the replay contract (§17). |
| `scar-list-v2.md` | 28 production lessons as acceptance criteria (8 engram-era + 20 bansai-era). |
| `decisions-triage.md` | Every v1 decision classified: property / earned / released / obsolete. |
| `test-triage.md` | v1's 86 test files: 24 P1 behavior tests to port from day one. |
| `log-audit.md` | Which mechanisms actually fired in production (live / insurance / never). |
| `replay-baselines.md` | Distributional baselines + replay-input inventory for validating this build. |

**Deliberately not copied here:** `store-design-memory.md` (the seventh harvest
output) quotes content from the owner's live memory store and stays in the bansai repo
(`~/bansai/docs/v2-harvest/`), which has a human-eye privacy pass on its flip
checklist. This repo is the one that goes public; reference that file across repos,
never copy it in.
