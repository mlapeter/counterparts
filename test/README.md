Tests land with the implementation they cover. The day-one spine was the 24 P1 behavior tests in docs/harvest/test-triage.md; the suite has grown well past it. All tests hermetic (fresh temp dir per test).

That last sentence used to be an instruction only, and an agent duly wrote a test that opened a store at `join(homedir(), ".counterparts", "x")` — beside the owner's live memory, four runs before anyone noticed. `test/preload.ts` (wired in `bunfig.toml`) now mechanizes it: before any test file loads it mints a temp dir, makes `homedir()` return it for the whole run, and unsets `COUNTERPARTS_DATA_DIR`, so the default data dir a forgetful test falls back to is a temp one and there is no real home left to reach. It redirects via `mock.module("node:os")` rather than `$HOME` because Bun's `homedir()` does not read `$HOME` at call time — setting the variable alone would look like a guard and be none. Since 2026-09-05 it also arms `COUNTERPARTS_REQUIRE_EXPLICIT_DIR=1`, so a test that names no dir is REFUSED (`IMPLICIT_DEFAULT_DIR_REFUSED`) rather than quietly redirected into the temp home; a test OF the fallback stands the guard down for its own body and re-arms it in `finally`.
