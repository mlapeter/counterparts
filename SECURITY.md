# Security

Counterparts stores personal memory on your machine, so security problems matter here.

Please report them privately, not in a public issue: use
[Report a vulnerability](https://github.com/mlapeter/counterparts/security/advisories/new)
on GitHub, or email mlapeter@gmail.com. Include what you found and how to reproduce it.
You'll get a reply within a few days.

Only the latest release on npm gets fixes.
